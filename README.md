# 🎮 Jogo de Pedra, Papel e Tesoura

Um jogo simples de **Pedra, Papel e Tesoura desenvolvido em Python**, criado com o objetivo de praticar conceitos fundamentais da linguagem, como funções, estruturas condicionais, laços de repetição, entrada de dados e geração de números aleatórios.

## 📌 Sobre o projeto

Neste projeto, o jogador escolhe entre:

* 🪨 Pedra
* 📄 Papel
* ✂️ Tesoura

A máquina realiza uma escolha aleatória e, em seguida, o programa verifica o resultado da rodada.

O projeto foi desenvolvido como parte da minha jornada de aprendizado em **Python**, buscando colocar em prática conceitos estudados através de exercícios e projetos.

## 🛠️ Tecnologias utilizadas

* **Python 3**
* Biblioteca `random`

## 📚 Conceitos praticados

Durante o desenvolvimento do projeto, foram utilizados conceitos como:

* Variáveis
* Entrada e saída de dados
* Estruturas condicionais (`if`, `elif`, `else`)
* Estruturas de repetição (`while`)
* Funções
* Validação de dados
* Números aleatórios com `randint()`
* Comparação de valores
* Organização e reutilização de código

## 🎮 Como executar

### 1. Clone o repositório

```bash
git clone https://github.com/BrendoBlacks/Jogo-De-Pedra-Papel-Tesoura.git
```

### 2. Entre na pasta do projeto

```bash
cd Jogo-De-Pedra-Papel-Tesoura
```

### 3. Execute o programa

```bash
python joquempo.py
```

## 🕹️ Como jogar

Ao iniciar o programa, será apresentada uma opção para o jogador escolher:

```text
[ 1 ] Pedra
[ 2 ] Papel
[ 3 ] Tesoura
```

Depois da escolha do jogador, a máquina fará sua escolha automaticamente.

O programa então informa se o jogador:

* 🏆 Venceu
* 💀 Perdeu
* 🤝 Empatou
